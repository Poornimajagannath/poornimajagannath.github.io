      Get a free PostHog key

      You don’t need a paid plan. Create a free PostHog account, add three GitHub secrets, and run one Action. That’s it.

      1. Sign up free at us.posthog.com/signup and create a project.
      2. Copy three values: phc_… project API key, numeric project ID, and a personal API key (phx_…) with dashboard:write, insight:write, web_analytics:read, query:read.
      3. In GitHub → Settings → Secrets → Actions, add POSTHOG_PROJECT_API_KEY, POSTHOG_PROJECT_ID, and POSTHOG_PERSONAL_API_KEY.
      4. Run the PostHog weekly report workflow once. It turns on tracking, creates your dashboard, and fills this page.
