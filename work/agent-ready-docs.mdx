---
title: Docs a person or an agent can follow
description: Public tools that check whether docs and generated code can actually be followed.
---

A doc can pass a link check and still fail when someone tries to finish a real integration. The same thing happens when a coding agent tries to follow it.

I lead the product direction for this on Visa Acceptance Platform (VAP). The check I care about is simple. Can a person, or an agent, follow the guide and finish the task?

The company launch is not on this page. What I can show are two public tools.

[docs-evals](https://github.com/Poornimajagannath/docs-evals) tests whether generated docs can answer a question and complete a task.

[code-verifier](https://github.com/Poornimajagannath/code-verifier) scans and sandboxes AI-generated code before anyone relies on it.

Status: public tools.
